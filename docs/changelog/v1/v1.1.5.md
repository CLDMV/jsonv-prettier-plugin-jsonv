# @cldmv/prettier-plugin-jsonv v1.1.5 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

A dev-dependency release: the test toolchain (Vitest 5.0.3 and its Vite and Rolldown packages), ESLint 10.12.0, `globals` 17.13.0 and three CLDMV development packages move forward in the lockfile. The net change against v1.1.4 is `package.json` (the version field only) and `package-lock.json`. No plugin code, published file or declared dependency range changed, and every moved package is a development dependency.

The one change worth knowing about is in the tooling's Node.js requirements. `@cldmv/vitest-runner` 1.5.3 declares `engines.node` `>=22.12.0` (it was `>=20.19.0`), and its `chalk` dependency moves from 5.6.2 to the 6.0.1 major, which requires Node.js 22 or later. Running the repository's tests already needed Node.js 22.12 or later because of Vitest 5, and the CI matrix starts at 22.12.0, so nothing changes in practice. The published plugin is not affected: its `engines.node` stays `>=18.0.0` and its runtime peer dependencies are untouched.

---

## 🔧 Dependencies

All changes are to development dependencies, and only the lockfile moved. The ranges in `package.json` are unchanged.

- **Vitest group** ([#56](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/56)): `vitest` and `@vitest/coverage-v8` 5.0.2 → 5.0.3, with `@vitest/mocker` and `@vitest/spy` at 5.0.3 and, transitively, `vite` 8.3.1 → 8.3.2, `rolldown` and its platform bindings 1.2.11 → 1.2.12, `@oxc-project/types` 0.151.0 → 0.152.0 and `why-is-node-running` 3.2.2 → 3.2.1 (the exact version Vitest 5.0.3 depends on, so this one moves down).
- **ESLint** ([#57](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/57)): `eslint` 10.11.0 → 10.12.0.
- **`globals`** ([#59](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/59)): 17.12.0 → 17.13.0.
- **Patch group** ([#60](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/60)):
  - `@cldmv/vitest-runner` 1.5.1 → 1.5.3. Its `engines.node` rises to `>=22.12.0` and its `chalk` dependency moves to 6.0.1, as described above. This is the only transitive tooling change with a Node.js requirement; `chalk` 6 is used by the test runner only.
  - `@cldmv/jsonv` 1.1.1 → 1.1.3 and `@cldmv/eslint-plugin-jsonv` 1.0.13 → 1.0.15. These are the locked development versions. The plugin's own `@cldmv/jsonv` peer range stays `^1.1.0`, so the 1.1.3 lockfile entry is what the plugin's tests run against, and consumers keep choosing their own version.
