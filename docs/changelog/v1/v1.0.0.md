## Overview

The first release of `@cldmv/prettier-plugin-jsonv`: a Prettier plugin that formats `.jsonv` files using the real [`@cldmv/jsonv`](https://github.com/CLDMV/jsonv) parser.

---

## ✨ Features

- A Prettier language, parser and printer for `.jsonv` files, wired through `@cldmv/jsonv`'s own parser.
- Printing for every jsonv node type: objects, arrays, literals, identifiers, member-expression references and template literals with interpolation.
- Line and block comment attachment to the AST so comments survive formatting.
- Configuration options `jsonvYear` (target ES-year feature set) and `strictBigInt`.
- Syntax-error reporting with line and column position.
- Idempotent formatting: formatting an already-formatted file produces no further changes.
- A bundled ESM build (`dist/index.mjs`) with generated TypeScript declarations, built with esbuild.

## 🔧 Dependencies

- Peer dependencies: `@cldmv/jsonv` `^1.0.0`, `prettier` `^3.0.0`.
