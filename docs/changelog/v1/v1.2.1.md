# `@cldmv/prettier-plugin-jsonv` v1.2.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/1.2.1`

---

## Overview

v1.2.0 raised `engines.node` from `>=18.0.0` to `>=22.22.0`. That number is the floor of the build and test toolchain, not something the plugin needs to run. This release puts `engines.node` back to `>=18.0.0` and records the toolchain floor separately in npm's `devEngines`, so projects on Node.js 18, 20 or early 22 releases can install v1.2.x again without an `EBADENGINE` warning.

The formatting code is unchanged, so a given `.jsonv` file formats exactly as it did in v1.2.0. The CommonJS entry's error message and the build target are the only other changes to what ships.

---

## 🐛 Bug Fixes

### `engines.node` describes the runtime again ([#88](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/88))

- `engines.node` is `>=18.0.0` again, as it was up to v1.1.4. The plugin has no runtime dependencies, and its peers are `prettier` `^3.0.0` and `@cldmv/jsonv` `^1.1.0`.
- The tsup build targets `node18` instead of `node20`, so the bundled `dist/index.mjs` matches that floor.
- The CommonJS entry's `ERR_REQUIRE_ESM` message now says `require()` needs Node.js ^20.19.0 or >=22.13.0 (the versions with `require(esm)`), instead of >=22.22.0. On Node.js 18, or a 20/22 release without `require(esm)`, load the plugin from an ES module config or with `import()`.

---

## 📦 Requirements

- **Runtime:** Node.js `>=18.0.0` (`engines.node`) and Prettier 3. A CommonJS Prettier config needs Node.js ^20.19.0 or >=22.13.0 for `require()`.
- **Development:** Node.js 22.22.0 or later, declared in the new `devEngines.runtime` field (`onFail: "error"`), so npm stops with an error when it is run in a checkout on an older Node.js.

---

## 🔧 CI & tooling

- The `min_node_version` input descriptions and a comment in `ci.yml` and `publish.yml` now say the 22.22.0 matrix floor is the dev toolchain floor and should match `devEngines`, not `engines` ([#88](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/88)). The matrix itself still starts at 22.22.0.
