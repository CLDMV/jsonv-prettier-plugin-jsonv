## Overview

A CI-only release that fixes the release workflow's own concurrency handling. No plugin code changed.

---

## 🐛 Bug Fixes

### Release-relevant CI runs are no longer superseded ([#7](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/7))

The `next`/`master` concurrency group derived its release base from a hardcoded `master`/`main` guess instead of the workflow's actual target branch, so a release-relevant run could be cancelled ("superseded") by a later, unrelated run landing in the same concurrency group — leaving a release PR's checks red for a run that never actually failed. The concurrency key now derives the release base correctly, so release-relevant runs are never superseded.
