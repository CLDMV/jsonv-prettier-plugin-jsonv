## Overview

A CI-only release that fixes the hotfix-redirector workflow's signing and re-aligns the test toolchain on `next`. No plugin code changed.

---

## 🐛 Bug Fixes

### GPG signing secrets wired into the hotfix redirector ([#20](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/20))

`hotfix-redirector.yml` was missing the GPG signing secrets, so a cherry-pick it made onto `hotfixes` was unsigned. The workflow now receives the same signing secrets as the rest of the release pipeline.

## 🔧 Dependencies

- `vitest` and `@vitest/coverage-v8` aligned on `5.0.0` on `next` (dev only; [#23](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/23)), matching the security bump already shipped to `master` in v1.0.5.
