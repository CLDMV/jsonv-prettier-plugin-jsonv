# prettier-plugin-jsonv v1.2.3 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

A packaging and tooling release; formatting is unchanged. The CommonJS entry is now the generic shim shared by the CLDMV libraries, and `require("@cldmv/prettier-plugin-jsonv")` returns the plugin object exactly as before. The test suite now also runs against the built `dist/`, CI cancels superseded runs, and the dev toolchain is refreshed.

---

## 📦 Packaging

### The CommonJS entry is the generic shim ([#107](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/107))

`src/index.cjs`, published as `dist/index.cjs`, is now the shim every CLDMV library ships instead of a hand-written `.default` unwrap. The package exports one value, the plugin, so `require("@cldmv/prettier-plugin-jsonv")` returns the plugin object, exactly as before. The CJS tests pin that shape.

---

## 🧪 Tests

### The suite runs against the build too ([#95](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/95))

The old `test:dist` only ran the CommonJS entry check, so it's `test:cjs` now. The new `test:dist` builds the package and runs the vitest suite with `--mode=dist`, so the tests that import the package by name run against `dist/`. A resolve test checks they loaded the right tree.

---

## 🔧 CI & tooling

- `ci.yml` adopts the CLDMV/.github v4.46.0 concurrency block, so superseded runs on `next`, `hotfixes` and the release PR are cancelled and only release pushes always finish ([#108](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/108), fixes [#106](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/issues/106)).
- `ci.yml` is synced with the v4.43.0 template ([#104](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/104)).
- The `sync-release-notes.yml` companion workflow syncs release bodies from these changelog files and creates missing version tags ([#102](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/102)).
