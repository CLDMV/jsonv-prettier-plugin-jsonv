# @cldmv/prettier-plugin-jsonv v1.0.5 Changelog

**Release Date**: September 2026
**Release Type**: Patch
**Availability**: GitHub Release only ([v1.0.5](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/releases/tag/v1.0.5)); not published to npm

---

## Overview

A hotfix release, shipped through the `hotfixes` lane rather than `next`, addressing a security advisory in the dev toolchain. No plugin code changed.

---

## 🔒 Security & supply chain

- `vitest` and `@vitest/coverage-v8` bumped to `5.0.0`, resolving [GHSA-82fw-gwwq-j7x9](https://github.com/advisories/GHSA-82fw-gwwq-j7x9) / CVE-2026-84373 (`@vitest/mocker` path traversal / arbitrary file read via a redirect mock, reachable through vitest's unauthenticated dev-server WebSocket) ([#22](https://github.com/CLDMV/jsonv-prettier-plugin-jsonv/pull/22)). Both are dev-only dependencies (the test toolchain); the published plugin package is unaffected.

---

## Upgrade notes

- No breaking changes — drop-in for v1.0.4. Projects that install this package's devDependencies directly should pick up `vitest`/`@vitest/coverage-v8` 5.0.0 or later.
